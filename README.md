# Java Number Guessing Game

A simple console-based Java game where the user attempts to guess a randomly generated number between 1 and 100.

## Features
- Random number generation
- User input with Scanner
- Loop until the correct guess
- Feedback if the guess is too high or too low
- Attempt counter

## Example Gameplay

```
Welcome to the Number Guessing Game! Guess a number between 1 and 100.

Enter your guess: 50
Too high!

Enter your guess: 25
Too low!

Enter your guess: 32
Correct! You guessed the number in 3 attempts!
```
